[View the gta6-trophy-guide-01 bounty](https://make.fun/bounty/gta6-trophy-guide-01). Leonida Ledger is an offline static guide and progress tracker for all 55 PlayStation 5 trophies in Grand Theft Auto VI.

## Use it

Serve the contents of `app/` as a static site or run `node serve.ts` from the repository root and open http://localhost:8080. No build or network connection is needed. Progress is stored in this browser; use Export and Import to move a checklist between browsers or devices.

## Guide notes

The roadmap orders chapter, mission strand, completion and activity work from the supplied PlayStation trophy descriptions. Every trophy guide names that list as its source. When the description omits a location or trigger, the guide says so instead of presenting an unverified detail as fact. The supplied list does not identify any missable trophy.
